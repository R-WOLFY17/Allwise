# AllWise Foundation Website

This repository contains the source code for the AllWise Foundation website, built to support and empower vulnerable communities globally.

## Overview
The AllWise Foundation website is a modern, responsive static website designed to showcase the foundation's mission, current programs, news, and to facilitate donations and volunteer involvement.

### Key Pages
- **Home (`index.html`)**: Overview of the foundation, key statistics, and featured programs.
- **About Us (`about.html`)**: Detailed background on our mission, vision, and team.
- **Programs (`programs.html`)**: In-depth information on our educational, healthcare, and food support initiatives.
- **Get Involved (`get-involved.html`)**: Volunteer and partnership opportunities.
- **News/Blog (`blog.html`)**: Updates, stories from the field, and recent announcements.
- **Gallery (`gallery.html`)**: Visual documentation of our impact.
- **Contact (`contact.html`)**: Ways to reach us and visit our physical location in Buikwe, Uganda.
- **Donate (`donate.html`)**: Information and methods for financially supporting the foundation's work.

## Technology Stack
- **HTML5**: For semantic structure.
- **CSS3** (in `assets/css/style.css`): Custom styling with a robust design system, CSS variables for theming, and responsive design patterns.
- **JavaScript**: For interactive elements like mobile navigation and basic form handling.
- **Lucide Icons**: Used throughout the site for lightweight, consistent iconography.

## Design Highlights
- **Responsive Navigation**: Mobile-friendly hamburger menu.
- **Modern Aesthetics**: Clean typography, card-based layouts, and smooth CSS transitions/animations (`animate-on-scroll`).
- **Consistent Footers & Headers**: Ensures easy navigation across all pages.

## Getting Started
To view or work on this project locally:

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. No build steps or local servers are required for basic viewing, though running a simple local server (like `python -m http.server` or via a VS Code extension like Live Server) is recommended for best results when editing.
